# 修复移动端视频背景未全屏问题

## 问题
移动端 `.blog-hero-section` 高度设为 `80vh`，但视频背景 `.blog-hero-fixed` 是 `100vh`，导致内容在 80vh 处就开始显示，视频下方露出内容。

## 修复方案
将移动端 hero section 高度改回 `100vh`，保持视频全屏覆盖。

## 修改文件
- `src/pages/blog.astro` — 移动端媒体查询中的 `.blog-hero-section` 高度

## 具体修改
```css
/* 修改前 */
@media (max-width:680px) {
  .blog-hero-section { height: 80vh; min-height: 400px; }
}

/* 修改后 */
@media (max-width:680px) {
  .blog-hero-section { height: 100vh; min-height: 100dvh; }
}
```

同时平板端也改为 100vh：
```css
@media (min-width:681px) and (max-width:960px) {
  .blog-hero-section { height: 100vh; }
}
```

## 验证
- 移动端访问 blog 页面，视频应全屏显示
- 滚动时内容应覆盖视频
- 桌面端不受影响

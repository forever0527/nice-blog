Docker 让应用部署变得简单一致。通过容器化，你可以确保应用在任何环境中都能正常运行。

## 核心概念

镜像、容器和仓库是 Docker 的三大核心概念。

## Dockerfile

编写高效的 Dockerfile 是优化镜像大小的关键。

## Docker Compose

使用 Docker Compose 可以轻松管理多容器应用。

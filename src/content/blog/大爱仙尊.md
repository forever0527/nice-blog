# 这是一级标题这是什么？
预埋件是大类统称，所有提前预埋进混凝土里的钢构件都叫预埋件；地脚螺栓是专门用来固定设备、钢柱的预埋锚栓，归属于预埋件施工时把整套 M30/M36 螺栓、垫板、固定钢圈提前固定在模板内，浇筑混凝土永久埋入，后期露出上段螺杆，用来锁紧钢结构立柱 / 设备底座，这个预埋安装过程，就属于设备基础预埋件施工。

## 二者包含关系

- 地脚螺栓（锚栓预埋件：螺杆 + 垫板 / 锚固板，你图纸里 M30、M36 都属于这类
- 预埋钢板、预埋角钢、预埋钢筋、预埋套管等其他预埋构件

### 地脚螺栓的预埋逻辑

1. 锚栓类预埋件（地脚螺栓）
   作用：承受竖向压力、水平剪力，固定钢柱、避雷针、设备机组；
   组成：圆钢螺杆 + 螺母 + 垫板 + 底部弯钩 / 锚固钢板
2. 平板预埋钢板
   作用：后期现场焊接钢梁、支架；
   组成：单块钢板 + 锚固钢筋，无螺杆，和地脚螺栓用途完全不同。

- 地脚螺栓是预埋件，但预埋件不只有地脚螺栓；做设备基础、钢柱基础时，地脚螺栓是核心预埋构件。
- 表中重量均为成品理论重量（含加工、下料余量），非纯毛坯钢板重量，可直接用于工程量结算、采购统计

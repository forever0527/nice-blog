Tailwind CSS 是一个实用优先的 CSS 框架，它让你可以直接在 HTML 中编写样式，而不需要写大量的 CSS 文件。

## 为什么选择 Tailwind

Tailwind 让你专注于构建界面，而不是纠结于命名类名。它的原子化设计让你可以快速迭代。

## 响应式设计

Tailwind 提供了简洁的响应式前缀系统，让移动端适配变得简单。

## 暗色模式

通过 `dark:` 前缀，可以轻松实现暗色模式适配。

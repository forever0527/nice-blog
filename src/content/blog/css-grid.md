CSS Grid 是 CSS 中最强大的布局系统之一。它让复杂的网页布局变得简单直观。

## 基础概念

Grid 容器、Grid 项目、Grid 线和 Grid 轨道是理解 Grid 布局的基础。

## 模板区域

Grid Template Areas 让你可以用可视化的方式定义布局结构。

## 响应式 Grid

结合 `auto-fit` 和 `minmax()`，可以创建完全响应式的网格布局。

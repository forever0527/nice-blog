React 不仅仅是一个 UI 库，它更是一种构建用户界面的思维方式。掌握设计模式能让你的代码更加优雅。

## 组合模式

组合模式是 React 中最基础也最重要的模式。通过将 UI 拆分为小的、可复用的组件，我们可以构建出复杂的界面。

## 自定义 Hook

自定义 Hook 是 React 中复用状态逻辑的利器。它让组件保持简洁的同时，又能共享复杂的行为。

## 渲染 Props

渲染 Props 模式允许组件将渲染逻辑委托给父组件，提供了极大的灵活性。

Git 是现代软件开发中不可或缺的版本控制工具。掌握正确的工作流能大大提高团队效率。

## 分支策略

Git Flow、GitHub Flow 和 GitLab Flow 是三种常见的分支策略，各有优劣。

## 提交规范

清晰的提交信息能让代码历史一目了然。推荐使用 Conventional Commits 规范。

## 代码审查

Code Review 是保证代码质量的重要环节，它不仅能发现 bug，还能促进知识共享。
